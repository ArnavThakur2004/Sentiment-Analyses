# Text Classification using Machine Learning and Deep Learning  

This project focuses on **text classification** using both traditional machine learning models and deep learning techniques. The dataset consists of preprocessed textual data, including **lemmatized tokens**, which are transformed using **TF-IDF vectorization** and **word embeddings** for model training.  

## 🔹 Project Overview  
- **Machine Learning Models Used:**  
  - Support Vector Machine (SVC)  
  - (Other classifiers can be added for comparison)  

- **Deep Learning Model Used:**  
  - LSTM-based neural network for text classification  

## 📌 Features  
✅ Preprocessing of text data using lemmatization  
✅ Feature extraction using **TF-IDF Vectorization**  
✅ Implementation of machine learning models to evaluate classification performance  
✅ Deep learning approach using **LSTM** for better text sequence understanding  
✅ Performance evaluation using **accuracy, precision, recall, and F1-score**  

## 📂 Dataset  
The dataset used in this project contains **lemmatized tokens** and **target labels** for classification.
